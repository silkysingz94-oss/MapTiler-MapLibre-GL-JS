3D TERRAIN & LoD1 BUILDINGS

Terrain visualisation

The terrain view uses MapTiler Terrain RGB elevation tiles and MapLibre terrain rendering. Adjust tilt and exaggeration to explore available relief.

LoD1-style building visualisation

Building footprints are retrieved from OpenStreetMap within the current map extent. Each footprint is extruded into a simple 3D block. Available height or level attributes are used where present. Missing heights are estimated using building levels or a fallback height. The output is suitable for visual exploration, not engineering, cadastral, structural or official building-height analysis.

METHODOLOGY & DATA NOTES

Network routing methodology

The dashboard requests a route from a routing engine and draws the returned route geometry. Driving, walking and cycling use different routing profiles when the routing service supports them. Route distance and duration are service estimates, not live traffic predictions. Availability and mapped network completeness vary.

GPS methodology

Device coordinates are obtained through the browser Geolocation API. Accuracy is reported by the device and may vary with satellite visibility, hardware, network conditions and obstructions.

Data limitations

Town coordinates are illustrative locations, not official administrative centroids. OSM building coverage and attribute completeness vary by location. Buildings without height attributes use estimated values. This dashboard does not replace authoritative GBoS boundaries, verified road data, surveyed building footprints or certified LoD1 data.
